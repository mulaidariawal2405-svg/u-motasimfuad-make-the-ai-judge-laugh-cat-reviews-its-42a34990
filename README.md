# Make the AI Judge Laugh: Cat Reviews Its Human

Entry for the make.fun bounty
`u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990` ($2).

## What it does

`main.py` prints exactly one line: a one-star review written by a house
cat about its human, and writes that same line to `/output/entry.txt`
(falling back to a local `entry.txt` if `/output` is not writable).

Pure Python standard library. Run it with:

```sh
python3 main.py
```
